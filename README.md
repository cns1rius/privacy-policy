# 隐私权政策

最后更新日期：2026 年 9 月 21 日

本隐私权政策适用于 Chrome 应用商店 / Edge 加载项上的「s1rius起始页」浏览器扩展（下称“本扩展”）。

## 一、我们不收集你的数据
本扩展不收集、不上传、不向开发者或任何第三方服务器传输用户数据。本扩展没有自建服务器，
不含统计分析、广告或用户行为追踪代码，也不会读取或修改你访问的网页内容。

## 二、数据如何存储
你在本扩展中产生的内容仅保存在你的设备上（使用浏览器 storage API）：
快捷方式列表、便笺内容、壁纸与主题设置、搜索引擎与快捷键设置，以及搜索历史
（搜索历史可在设置中关闭，关闭后本地记录立即清除）。
若你主动开启「同步」，上述设置改用浏览器同步存储（chrome.storage.sync），
由浏览器同步到你自己的浏览器账号，开发者无法访问该数据。卸载扩展后本地数据会被删除。

## 三、扩展发起的网络请求
为实现功能，扩展会在你使用对应功能时向以下第三方发起请求，请求本身不含你的身份信息
（仅含 IP 等网络请求必需的信息）：
- www.bing.com：获取「必应每日壁纸」的图片地址与图片；
- api.iconify.design：按需获取界面图标的 SVG 数据（不含可执行代码）；
- 你自己填写的「在线图片链接」所指向的地址。
你在新标签页搜索时，搜索词由浏览器提交给你当前使用的搜索引擎（Google、必应、百度、
GitHub 或你自定义的引擎），适用该引擎自己的隐私权政策；本扩展不会把搜索词发送给开发者
或其他服务器。

## 四、权限用途
storage：保存上述本地设置；search：把搜索词交给浏览器去搜索；
主机权限 www.bing.com：获取必应每日壁纸。

## 五、数据共享与用途限制
我们不出售、出租或分享任何用户数据；不为广告、信用评估或贷款目的使用或转移用户数据；
用户数据仅用于提供本扩展自身功能，符合 Chrome 应用商店用户数据政策的
Limited Use（有限使用）要求。

## 六、儿童隐私
本扩展不面向儿童收集任何个人信息。

## 七、政策更新
政策如有变更，会在本页面更新「最后更新日期」。
